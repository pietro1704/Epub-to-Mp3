# Goal plan execute

Read `docs/agent-workflow.md` and follow its focused implementation sequence,
acceptance oracle and review criteria. Use `docs/agents/execution-policy.md`
for platform ownership, safety and delivery authorization.

A clear, bounded change can start directly with inspection and implementation.
Write a short plan only for material uncertainty or dependent work. Load only
the affected runtime's instructions. Delegate only when authorized and useful.

For parser or rendering changes, compare source fidelity explicitly: labels,
hierarchy, markup, resources, links and fallback. Report executed evidence,
unresolved acceptance and delivery state.
