# Portable agent pipeline

Read `docs/agent-workflow.md` and follow its focused implementation sequence,
acceptance oracle and review criteria. Use `docs/agents/execution-policy.md`
for platform ownership, safety and delivery authorization.

Load the affected runtime's navigation and `CODING_STANDARDS.md`. A clear,
bounded change needs no additional planning phase. Delegate only when
authorized and useful. Report executed evidence and pending acceptance;
evaluate out-of-scope findings before expanding the task.
